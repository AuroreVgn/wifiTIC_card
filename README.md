# WiFiTIC Card

Carte Lovelace personnalisée pour Home Assistant, destinée aux compteurs Linky équipés d’un module **WiFiTIC CARTELECTRONIC**.

## Objectif

Visualiser les informations du compteur dans Home Assistant :

- Consommation électrique
- Injection réseau
- Puissance instantanée
- Périodes tarifaires

## Intégration

Cette carte est destinée à fonctionner avec [l’intégration WiFiTIC](https://github.com/AuroreVgn/wifiTIC).

> Le code JavaScript de la carte n’a pas encore été ajouté. Ce dépôt n’est pas encore installable via HACS.
